Información Personal

Configura los datos básicos del evaluador que se agregará a tu equipo.

Tipos de Evaluador:
  • Evaluador: Permisos básicos de evaluación
  • Revisor: Puede revisar y aprobar evaluaciones
  • Analista: Acceso a análisis y reportes avanzados
  • Administrador: Permisos completos del módulo
Configuración de Módulos

Selecciona los módulos a los que tendrá acceso el evaluador.

Consejo: Solo aparecen los módulos de tus suscripciones activas. El evaluador heredará el acceso básico a estos módulos.
Permisos CRUD Detallados

Define permisos específicos para cada módulo seleccionado.

Tipos de Permisos:
  • Crear: Añadir nuevos elementos
  • Consultar: Ver y buscar información
  • Editar: Modificar elementos existentes
  • Eliminar: Borrar elementos (¡cuidado!)
  • Exportar: Generar reportes
  • Aprobar: Validar elementos
Restricciones y Límites

Establece límites y permisos globales del sistema.

Importante: Estos límites se aplicarán independientemente de los permisos CRUD configurados.
